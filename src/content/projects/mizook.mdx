## Background

Mizook is a personal assistant that lives in Telegram and on the web, on Cloudflare Workers. It is one or more agents, and each one is a chat that never ends: an agent remembers everything said to it, and nothing needs resetting.

## What it does

- **Memory.** The whole chat is logged word for word and compressed into a binary tree of one-line summaries. Each turn sees a constant-size view and zooms in where it needs more.
- **Durable turns.** Model and tool calls are committed to the Durable Object's SQLite before anything is shown, so a restart picks a turn up where it stopped.
- **Code mode.** The model gets two tools, `send_to_user` and `execute`. Everything else is a function that a JavaScript program calls, so one program can chain many calls.
- **Agents.** Each agent has its own memory, persona, model, and tool list. An agent can create a new one, such as a fact-checker, after you approve it.
- **Automations.** One-off, cron, URL watch, and webhook triggers that start an agent turn or post a message.
- **Artifacts.** Pages and files at their own sandboxed URLs, with versions kept in R2.
